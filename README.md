# 🍔 FoodDelivery – User App (Android)

A native Android food delivery application that allows users to discover restaurants, browse menus, place orders, and track deliveries in real time — built with modern Android architecture and best practices.

## ✨ Features

- 🔍 Browse nearby restaurants & cuisines  
- 📋 View detailed menus with images & prices  
- 🛒 Add items to cart & manage order summary  
- 💳 Secure checkout with multiple payment options  
- 📍 Real-time order tracking with live map  
- ⭐ Rate & review completed orders  
- 🔔 Push notifications for order updates  
- 👤 User authentication (email/phone + OTP)

## 🛠️ Tech Stack

- **Language**: Java  
- **Architecture**: MVVM + Repository Pattern  
- **Networking**: Retrofit, OkHttp  
- **Database**: Room (local), Firebase Firestore (remote)  
- **Location & Maps**: Google Maps SDK 
- **Push Notifications**: Firebase Cloud Messaging (FCM)  
- **Build Tools**: Gradle, Android Studio  
- **CI/CD**: GitHub Actions 

## 📱 Screens

- Splash Screen  
- Onboarding / Login / Signup  
- Home (Restaurant List)  
- Restaurant Detail & Menu  
- Cart & Checkout  
- Order Tracking (Map + Status)  
- Order History & Ratings
